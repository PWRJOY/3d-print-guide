# 维护保养与易损件

规律维护比出故障后抢修更省时。下表给出建议检查周期，具体寿命受打印时长、材料与使用强度影响；纤维增强材料会加快喷嘴与喉管磨损。

## 1. 维护周期表

| 项目 | 周期建议 | 检查与处理 |
| --- | --- | --- |
| 打印板面清洁 | 每次取件后 | 异丙醇去除残留与油污；检查划痕、老化与粘附力 |
| 耗材密封存放 | 日常 | 未用完线材立即密封加干燥剂；高吸湿材料上机前干燥 |
| 空气滤芯 | 按官方周期 | 更换 G3 初效与 H12 HEPA、活性炭滤芯，过滤失效会影响气味与颗粒控制 |
| 喷嘴检查 | 出现出料异常时；定期目视 | 磨损、堵料、流道变形时更换；X2D 支持免工具换喷嘴 |
| 流量与振动补偿校准 | 换喷嘴、搬动机器、拆装热板后 | 在设备校准入口重新执行 |
| 运动部件 | 按使用时长 | 检查导轨顺畅度、皮带张紧与异响；按官方说明润滑导轨 |
| 传感器与镜头 | 定期目视 | 清洁摄像头与传感器窗口，保证 AI 监测与调平准确 |
| 固件更新 | 版本发布后 | 先阅读更新说明，更新后回归基础测试件 |
| 废料滑梯与废丝通道 | 每次长任务前后 | 确认通道畅通，避免堵塞触发暂停 |

## 2. 易损件清单

- 喷嘴（不同直径备用：0.2 / 0.4 / 0.6 / 0.8 mm）。
- 空气滤芯套装（初效、HEPA、活性炭）。
- 打印板（纹理 PEI、光面 PEI、工程材料板按需备用）。
- 进料管、挤出齿轮、弹簧等挤出系统易损件。
- 干燥剂与密封存储容器。

## 3. 日常开机检查

1. 打印板清洁、安装到位，无残留废料。
2. 耗材安装顺畅，余量充足，密封状态正常。
3. 摄像头视野无遮挡，镜头干净。
4. 废料滑梯与废丝通道无堵塞。
5. 确认环境温度在 10–30 ℃ 范围内。

## 4. 什么情况需要深度维护

- 同一类表面问题反复出现，校准与材料排查后仍不稳定。
- 运动出现异响、偏差或振动补偿后仍有明显振纹。
- 纤维增强材料长期使用后喷嘴流量与出料不稳定。
- 滤芯压差明显、异味或通风异常。

深度维修与部件更换流程以官方 Wiki 与售后指导为准；在未确认部件结构前不要自行拆卸运动系统与电气部分。
