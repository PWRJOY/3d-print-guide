# 专家进阶：原理、维修与拓展

本板块面向已经能稳定完成日常打印、希望理解底层机制并独立排障的使用者。目标不是记住别人的参数配方，而是面对新材料、新模型时能预判问题、给出方案。

## 1. 底层原理

### 挤出与流量模型

- 挤出机送料量、喷嘴流道截面积、材料膨胀与实际线宽之间的对应关系。
- 流量校准为什么能补偿喷嘴磨损、残留与轻微受潮；动态流量校准与固定 K 值校准的区别。
- 挤出压力波与回抽、空置移动路径如何影响表面拉丝。

### 热传导与层间结合

- 喷嘴温度、热床温度、腔温与冷却风扇如何共同决定层间热量。
- 为什么不同材料需要不同冷却策略：PLA 快速定型，工程材料保持层间热量。
- 大尺寸件内外温差、收缩梯度与翘曲、层裂的关系。

### 收缩与尺寸补偿

- 材料冷却收缩方向与打印方向的关系。
- 轴孔补偿、配合间隙与实测尺寸偏差的校正方法。
- 环境温度波动对大尺寸件尺寸稳定性的影响。

### 运动与振动

- 共振、加速度与速度如何在侧壁形成振纹与鬼影。
- 振动补偿的测量原理；皮带松弛与机械磨损为什么需要定期检查。

### 冷却风场

- 双风道冷却如何影响悬垂、桥接与顶面；风速、风向与材料定型速度的匹配。

## 2. 维护与维修能力

- 热端、喉管、喷嘴的结构与更换流程；堵头从冷拔到换件的判断边界。
- 挤出系统：齿轮磨损、送料打滑、线材路径故障定位。
- 运动系统：皮带张紧、导轨润滑、异响与偏差排查。
- 电气与传感器：断料、缠料、开门检测、摄像头异常的判读顺序。
- 维护记录：建立自己机器的打印时长、易损件更换与故障档案。

## 3. 进阶切片策略

- 填充结构选择与受力方向匹配。
- 墙体、接缝、外壁顺序与外观面管理。
- 多件排版：板面利用率、温度场干扰、支撑与避让。
- 自定义工艺配置文件：按材料、喷嘴直径与模型类型建立可复用预设。
- 多材料组合设计：主体、支撑、柔性件与颜色分区的规划方法。

## 4. 拓展方向（按需深入）

- **AMS 多色系统**：多色轮换、余料管理与配色方案。
- **3D 扫描与逆向建模**：实物扫描、网格修复、改型后再打印。
- **树脂光固化工艺**：与 FDM 的精度、材料、后处理差异，作为工艺对比补充。
- **第三方切片**：OrcaSlicer、PrusaSlicer、Cura 的参数体系与官方智能功能差异。
- **小批量制作**：排版、一致性、后处理流程与成本控制。
- **材料探索**：发泡材料、复合材料、特种功能材料的官方指南先行。

## 5. 专家判断标准

- 拿到陌生材料：先查物性、温度窗口、吸湿特性与兼容喷嘴，再制定参数方案。
- 拿到复杂模型：先判断摆放方向、支撑需求、受力方向与配合间隙，再切片。
- 出现故障：按基础条件 → 材料 → 校准 → 参数 → 硬件的顺序系统排查，而不是逐项试参数。
- 所有结论以测试件与实测结果验证，保留可复现的参数记录。
