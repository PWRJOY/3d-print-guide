# 4. 第一组测试件

## 4.1 测试件顺序

按从简单到综合的顺序打印，不要一上来打复杂模型：

1. **首层测试片**：判断喷嘴高度、调平与板面附着是否正确。
2. **校准方块 / 基础几何件**：观察侧壁、顶面、尺寸与层纹。
3. **Benchy 小船**：公认的综合质量测试模型，同时暴露悬垂、桥接、圆弧、侧壁与顶面表现。

模型从 MakerWorld 选择标注适配 X2D、使用官方 PLA 配置的文件，直接沿用预设切片。

## 4.2 打印中重点观察什么

- **前 3–5 层**：首层是否平整铺开、紧贴板面，有没有局部不粘、拉丝或挤出不足。
- **侧壁**：层纹是否均匀，有没有明显挤出波动、振纹或缺料。
- **悬垂与桥接**：在官方预设下的基础表现，先记录现象，不急于改参数。
- **AI 监测**：留意摄像头是否触发炒面、裹头或堵塞告警；告警时按界面提示处理。

## 4.3 首打成功标准

- 首层均匀附着，边缘不翘起，取件时板面无明显拉伤。
- 侧壁连续、无大面积缺料；顶面封闭平整。
- 模型尺寸与预期基本一致，没有明显变形。
- 全程无堵头、无缠料、无异常报警中断。

## 4.4 失败了怎么处理

不要同时调整多个参数。先对照 [缺陷排查手册](/troubleshooting/) 定位现象：

- 首层不粘、翘边 → [附着不良与翘边](/troubleshooting/adhesion-warping)
- 表面拉丝 → [拉丝与牵丝](/troubleshooting/stringing)
- 出料中断、堵头 → [堵头与出料中断](/troubleshooting/clogging)
- 侧壁粗糙、振纹 → [表面质量问题](/troubleshooting/surface-quality)

把本次模型、耗材、参数、现象照片与处理改动记入打印日志。
