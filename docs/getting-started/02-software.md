# 2. 软件安装与配网

## 2.1 三套软件分别做什么

| 软件 | 运行位置 | 主要用途 |
| --- | --- | --- |
| Bambu Studio | 电脑端（Windows / macOS / Linux） | 模型导入、切片、参数配置、生成发送到机器的 G 代码 |
| Bambu Handy | 手机端 | 绑定设备、远程监控、延时摄影、手机选模型打印 |
| 机器触摸屏 | 打印机本机 | 启停任务、查看状态、执行校准、切换耗材 |

## 2.2 安装 Bambu Studio

1. 从拓竹官方渠道下载对应操作系统的最新版本并安装。
2. 首次启动后在设备列表中添加 X2D，按界面提示完成 Wi-Fi 配网与账号绑定。
3. 确认软件与机器固件为当前稳定版本；有更新时先阅读更新说明，再执行升级。

## 2.3 绑定 Bambu Handy

1. 手机应用商店安装 Bambu Handy，登录与电脑端同一账号。
2. 在应用中选择已绑定的打印机，确认可以看到实时状态与摄像头画面。
3. 熟悉界面中的任务列表、耗材状态、摄像头与延时摄影入口。

## 2.4 认识 Bambu Studio 界面分区

- **模型区**：导入 STL/3MF 模型，摆放、缩放、旋转与复制。
- **右侧参数面板**：层高、线宽、壁厚、填充、支撑、速度、温度、冷却等切片参数。
- **设备与耗材选择**：选择打印机型号、喷嘴直径与当前耗材；官方耗材的预设参数会自动匹配。
- **切片与发送**：点击切片预览路径，确认后发送到打印机。

第一周保持官方预设，不展开自定义参数；参数逐项解释见 [切片教程](/slicer/)。

## 2.5 首页与模型来源

- MakerWorld 是拓竹社区模型平台，模型多已针对对应机器调校好参数；下载时先看作者标注的适用机型与打印备注。
- 自己的模型统一保存为 `.3mf` 项目文件（保留参数与位置），而不是只保存 G 代码。

## 2.6 本节过关标准

- [ ] 电脑端 Bambu Studio 与手机端 Handy 均已绑定同一台 X2D。
- [ ] 能在电脑端看到机器在线状态，手机端能打开摄像头监控。
- [ ] 能说出模型区、参数面板、设备耗材选择、切片发送四个分区的作用。
