# 1. 开箱清点与环境准备

## 1.1 拆箱前准备

- 选择稳固、通风、留出散热空间的台面；机器周围不要堆放纸张、线材等易燃物。
- 工作环境温度要求 **10–30 ℃**，避免阳光直射、空调直吹与粉尘较大的位置。
- 确认插座电压与机身电源标签一致；高压版适配 200–240 V，低压版适配 100–120 V，通电前核对清楚。
- 在组装完成前不要连接电源（以随机快速指南为准）。

## 1.2 清点配件

对照随机《快速入门指南》逐一核对：主机、打印板、随机耗材、工具包、喷嘴、电源线、滤芯与说明书。发现缺件或运输破损，先联系售后，不要强行装机。

## 1.4 环境与安全要点

- 机器运行时喷嘴、热床与腔体内温度很高，不要把手伸入打印区域；取件等待热床与喷嘴降温。
- 三级过滤系统（G3 初效 + H12 HEPA + 活性炭）需安装到位；按周期更换滤芯，不要长时间拆下过滤运行。
- 线材、工具远离运动部件；打印中不要开盖遮挡风道。
- 首次通电前阅读机身上的警示标识与官方 Wiki 的安全说明。

## 1.5 X2D 本机先了解的几件事

- **双喷嘴分工**：主喷嘴打印模型主体，辅助喷嘴承担支撑与换色；辅助喷嘴打印质量略低于主喷嘴，辅助喷嘴优先使用官方耗材。
- **主动腔温**：最高 65 ℃，工程材料打印时依靠腔温保持层间结合与尺寸稳定。
- **AI 摄像头**：打印前扫描打印板异物与板面位置，打印中监测炒面、裹头与废料滑梯堵塞；保持镜头清洁。
- **免工具换喷嘴**：喷嘴堵塞或磨损后可快速更换；更换流程见 [维护保养](/maintenance/)。

- [ ] 说得出主喷嘴与辅助喷嘴的分工区别。
