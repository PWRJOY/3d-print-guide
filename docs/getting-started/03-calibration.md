# 3. 首次校准

## 3.1 校准前检查

- 确认喷嘴尖端无残留耗材与碎屑；喷嘴中未装入异物。
- 检查 PEI 打印板表面，用异丙醇去除指纹、油污与残留胶；板面安装平整、卡到位。
- 耗材使用随机官方 PLA；未用完的线材后续按 [吸湿与存储](/materials/drying-storage) 规范密封保存。
- 机器放置平稳；搬动过机器、拆装过热板或长期存放后，都需要重新执行调平。

## 3.2 执行自动校准

在 Bambu Studio 的「设备 → 校准」中按向导依次完成：

1. **热床调平**：自动测量板面高度差异，建立喷嘴与热床的基准距离。
2. **流量校准**：建立挤出量与实际出料的对应关系；X2D 仅主喷嘴具备主动流量校准。
3. **振动补偿**：测量运动系统共振，补偿高速下的振纹与鬼影。
4. 按向导提示完成喷嘴高度与其他机器要求的自检项。

也可以在机器触摸屏或 Bambu Handy 的设备设置中进入校准入口。

## 3.3 打印前再次确认

- 发送任务前勾选「热床调平」（如界面提供该选项），让任务开始前再做一次快速调平对比。
- 确认耗材路径顺畅，线材没有缠绕、打结；进料管与挤出机入口位置正确。
- 观察 AI 摄像头在打印前的板面扫描结果，确认板上无异物、板面位置正确。

## 3.4 什么时候需要重新校准

- 搬动、倾斜或重新放置机器之后。
- 更换、拆装打印板之后。
- 更换喷嘴、清理热端之后。
- 首层出现大面积附着不良，且排除板面脏污与耗材受潮之后。
- 更换关键运动部件或长期未使用之后。

## 3.5 本节过关标准

- [ ] 板面清洁、安装到位，耗材为干燥的官方 PLA。
- [ ] 按向导完成调平、流量校准与振动补偿，流程无报错。
- [ ] 知道哪些场景需要重新校准，而不是一遇到问题就反复盲目校准。
