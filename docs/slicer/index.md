# 切片教程（Bambu Studio）

切片软件把三维模型转换成打印机逐层执行的路径。本板块逐项解释参数的作用、调整方向与常见误区；新手阶段始终以官方预设为起点，一次只改一个变量。

## 学习顺序

1. [层高与表面质量](/slicer/layer-height)：先理解层高如何决定细节与打印时长。
2. [壁厚、线宽与填充](/slicer/walls-infills)：决定零件强度、用料与刚性。
3. [支撑策略与摆放方向](/slicer/supports)：减少支撑、改善接触面质量。
4. [速度、温度与冷却](/slicer/speed-cooling)：层间结合、表面与稳定性的平衡。
5. [接缝与外观优化](/slicer/seams)：把可见接缝藏到不显眼的位置。

## 新手使用原则

- 先用官方耗材对应的官方预设切片，不要一开始自建参数体系。
- 每次只修改一类参数，打印对比件后再决定是否保留改动。
- 参数调整要能说出预期改善什么问题；说不清目的的改动不要做。
- 保留 `.3mf` 项目文件，便于回溯当时的模型位置与参数组合。
