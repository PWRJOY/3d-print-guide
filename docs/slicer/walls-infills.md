# 壁厚、线宽与填充

## 外壁与内壁

- **外壁（walls/perimeter）**：零件最外层的连续路径，决定表面质量、尺寸精度与侧壁强度。
- **内壁**：外壁以内的轮廓路径，参与内部刚性，外观不可见。
- 壁厚通常按线宽的整数倍设置，避免半线宽路径造成挤出不均。0.4 mm 喷嘴下，实体壁厚建议至少 1.2–1.5 mm。

## 线宽

线宽是单道挤出路径的宽度，与喷嘴直径相关；线宽设置过宽会挤出量不足，过窄会溢料变形。先用官方默认线宽，不要凭感觉加宽或收窄。

## 填充（infill）

填充是零件内部的结构密度与图案：

- **展示件、外壳**：低密度填充即可，重点是外壁封闭。
- **功能受力件**：提高填充比例，并选择合理的填充图案。
- **卡扣、铰链、薄壁件**：局部区域需要接近实体填充，设计时在模型中预留加厚区域。
- 填充强度受打印方向影响；层间结合始终是薄弱截面，受力方向要尽量避开层间分离面。

## 顶面层与底面层

- 顶层数量不足会出现顶面凹陷、透空与条纹；顶面外观件按预览效果增加顶面层数。
- 底层数量保证首层附着与底面封闭；直接贴床的大面积底面注意首层参数。
