# 支撑策略与摆放方向

## 什么时候需要支撑

当悬垂角度超出材料在无支撑状态下的成型能力时，需要支撑托住悬空路径。常见需要支撑的结构：

- 大角度悬空底面、水平悬挑。
- 模型内部通道、倒扣与凹槽。
- 悬空的圆弧、桥梁跨度超过桥接能力的部分。

## 先改摆放，再加支撑

支撑不是第一选择。摆放方向调整往往能减少甚至消除支撑：

1. 把大平面转向贴床或自支撑角度。
2. 观察模型在不同朝向下的悬垂面与接触面。
3. 把需要高质量外观的面避开支撑接触面。

## 支撑参数关注点

- **支撑角度阈值**：低于该角度的区域自动生成支撑，按模型与材料逐步测试。
- **支撑接触面**：与模型贴合的第一层密度与间距，影响表面痕迹与剥离难度。
- **支撑间距与图案**：兼顾剥离便利性与支撑稳定性。
- **剥离方向**：设计与摆放时预留支撑拆除空间，避免支撑卡在无法伸入的内部结构里。

## 开启支撑后，预览里看不到支撑怎么办

支撑不是模型自带的，而是**切片时才计算生成**的。在 Bambu Studio 的「准备」页签，3D 视图只显示模型与打印板；开启支撑后看不到支撑属于正常现象，不代表设置失效。

确认支撑是否生成：

1. 点击「切片单盘」，或切换到「预览」页签（软件会自动触发切片）。
2. 切片完成后，预览视图里会用与模型不同的颜色与结构显示支撑；树状支撑呈悬空的树枝状。
3. 查看切片统计中的支撑体积、支撑面积与支撑耗材用量——数值为 0 说明当前设置下模型不需要支撑；数值越大说明支撑越多。

### 为什么开了支撑，切片后仍然没有支撑

- 支撑角度阈值（如 30°）：只有悬垂角度**超过**阈值的区域才生成支撑；模型没有大角度悬垂时不会出现支撑。
- 「树状（自动）」类型只在算法判定需要的位置生长支撑，不会全模型铺满。
- 模型朝向影响很大：同一个模型换个摆放方向，支撑量可能从「很多」变成「没有」——这正是上面「先改摆放，再加支撑」的原因。

## X2D 双喷嘴支撑

X2D 主喷嘴打主体、辅助喷嘴打支撑：易拆支撑材料或 PVA 水溶支撑可以处理复杂内腔，详见 [双喷嘴专题](/dual-nozzle/)。

## 桥接

两段之间悬空的水平路径称为桥接；桥接依靠冷却与材料张力成型，速度与冷却要匹配，先在测试桥上验证当前参数表现。
