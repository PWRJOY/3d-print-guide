# 接缝与外观优化

## 接缝从哪里来

每一层轮廓路径都有起点与终点；起点位置叠在侧壁上形成可见的竖向接缝。接缝位置、收敛方式与外观参数共同决定侧壁瑕疵是否显眼。

## 常用控制方式

- **接缝位置策略**：把接缝集中到背面、平面或角落等不显眼的一侧，而不是随机散布。
- **接缝收敛（seam alignment / smoothing）**：让相邻层接缝位置尽量对齐，减少侧壁错位痕迹。
- **外壁顺序与叠层策略**：先外后内，保证外壁连续顺滑。
- **回抽设置**：接缝处减少堆料与拉丝，兼顾表面与牵丝。

## 外观件检查顺序

1. 摆放方向把外观面朝外，接缝藏到非展示面。
2. 确认外壁参数与线宽匹配，避免接缝处堆料。
3. 顶面、圆弧与悬垂按对应参数单独核对。
4. 最后再处理表面打磨与上色，见 [后处理](/post-processing/)。

## 常见误区

- 只靠软件接缝隐藏解决所有外观问题：料量、温度、冷却与摆放方向才是基础。
- 为消除接缝过度降低速度：先确认是接缝位置问题还是挤出波动问题。
