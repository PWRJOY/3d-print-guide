# 速度、温度与冷却

## 三组参数如何互相影响

- **喷嘴温度**：决定材料熔融流动性与层间热量结合。温度偏低结合弱、出料不畅；偏高则拉丝、糊料、表面过软。
- **冷却风扇**：决定刚挤出材料的定型速度。PLA 需要充分冷却定型细节；ABS、ASA、PC 等材料需要降低冷却、保持层间热量。
- **打印速度**：决定挤出机供料与热端熔化是否跟得上。速度过快会导致出料不足、层间结合差；速度过慢降低效率，也可能让局部材料过热。

三者不是独立调节：改温度要复查冷却，改速度要复核流量与结合质量。

## 起步方法

1. 使用材料对应的官方预设速度与温度窗口。
2. 出现层间问题时，按 [层间分离与开裂](/troubleshooting/layer-separation) 的步骤小步调整温度与冷却。
3. 出现拉丝时，优先排查干燥与回抽，再考虑降温，见 [拉丝与牵丝](/troubleshooting/stringing)。
4. 高速打印出现振纹与边缘模糊，先确认振动补偿已执行，再考虑降速，见 [表面质量问题](/troubleshooting/surface-quality)。

## 流量与挤出

- 流量校准保证每一层挤出量与路径宽度匹配；X2D 主喷嘴具备主动流量校准。
- 侧壁偏厚、表面溢料或局部凹陷，先回到流量校准与线宽检查，不要直接手动堆参数。
