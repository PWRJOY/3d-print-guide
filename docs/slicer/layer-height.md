# 层高与表面质量

## 层高是什么

层高是每一层挤出材料的厚度，直接决定侧壁可见的层纹密度：层高越小，表面越细腻、圆弧过渡越平滑，但打印时间越长；层高越大，速度越快、用料越省，层纹越明显。

## 常见选择

- **0.20 mm**：通用默认值，兼顾表面质量与速度，功能件与普通展示件起步使用。
- **0.12–0.16 mm**：外观件、手办、圆弧表面，追求细腻侧壁。
- **0.24–0.28 mm**：快速原型、大尺寸功能件，接受明显层纹换取速度。
- 喷嘴直径决定可用层高范围；0.4 mm 喷嘴是最通用的组合。

## 层高与强度

- 层高偏大时，层与层之间接触面积变化，侧壁刚性与外观需要权衡。
- 受力件不要盲目追求薄层高；壁厚、填充与打印方向对强度的影响通常更大。

## 常见误区

- 为了好看把所有件都设成最薄层高：先判断这件是否需要外观面，功能件按强度与效率选择。
- 只改层高不同步观察冷却与结合：层高变化后，单层热量与冷却时间也随之改变。
