# 吸湿、干燥与存储

## 为什么必须管理耗材水分

多数 FDM 线材会从空气中吸收水分。受潮线材在喷嘴内受热时水分汽化，表现为：表面气泡、噼啪声、拉丝加剧、层间结合下降、表面粗糙、尺寸强度异常。材料越偏工程塑料，吸湿问题越突出。

## 吸湿程度排序（由弱到强）

- 相对不敏感：PLA（仍需密封存放）。
- 中等吸湿：PETG、TPU、ABS、ASA。
- 高吸湿：PA 尼龙、PVA、部分工程共聚酯。

具体吸湿速率与干燥条件以耗材厂商数据表为准。

## 存储规范

1. 未用完的线材立即放入密封袋或密封盒，加入干燥剂；避免长期暴露在空气中。
2. 开封线材尽量连续用完；长期存放的线卷保持密封、避光、远离热源。
3. 干燥后的线材上机后，剩余部分及时收回密封容器。
4. 干燥剂定期检查更换；变色干燥剂失效后按说明再生或替换。

## 干燥原则

- 干燥温度与时长严格遵循耗材厂商说明；不同材料不能套用同一干燥窗口。
- 干燥后先打小测试件，观察气泡、表面与层间结合是否改善，再进入正式打印。
- 不要把材料长时间放在过高温度下，避免材料老化变形。
- PVA 水溶支撑材料同样极易吸湿，存放要求比主体材料更严格。

## 上机前快速判断

- 出料时有明显噼啪声、表面出现气泡与麻点，优先怀疑受潮。
- 同一种材料更换干燥批次后缺陷消失，即可确认水分是主因。
- 把耗材批次、干燥时间与现象记入打印日志，逐步建立自己材料的存放记录。
