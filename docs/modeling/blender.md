# Blender 有机造型

## 定位

Blender 面向自由形态网格建模与雕刻，适合角色、手办、异形曲面与艺术外观件；它与参数化 CAD 是两套思维，在完成规则零件建模练习后再进入。

## 学习重点

1. 界面导航、物体模式与编辑模式切换。
2. 网格基础：顶点、边、面，挤出、细分、平滑与布尔。
3. 雕刻工具与动态拓扑，塑造有机形体。
4. UV、表面细节与网格修复。

## 打印前必须处理的网格问题

- 模型必须是闭合实体，检查非流形边、内部面与破面。
- 给薄壁有机件补充均匀壁厚，避免零厚度面无法切片。
- 检查悬垂与支撑需求，必要时拆分零件分别打印再粘合。
- 大尺寸手办按打印板尺寸拆件，预留拼接结构。

## 工具配合

- 网格修复与壁厚检查可配合专用网格工具；切片前在 Bambu Studio 中查看模型诊断结果。
- 有机件后处理工作量通常高于工程件，参考 [后处理工艺](/post-processing/)。
