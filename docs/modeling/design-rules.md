# DfAM 面向 3D 打印的设计规范

DfAM（Design for Additive Manufacturing）指在建模阶段就考虑成型工艺、强度与后处理，而不是先建完模型再想办法打出来。

## 1. 壁厚与线宽配合

- 实体壁厚建议为线宽的整数倍；0.4 mm 喷嘴下最小实体壁厚约 1.2–1.5 mm。
- 过薄的壁容易变形、开裂；过厚会拉长打印时间并累积内应力。
- 薄壁受力件在模型中主动加厚，而不是靠填充补强度。

## 2. 悬垂与支撑

- 超过材料自支撑角度的底面需要支撑；建模时优先调整结构走向，减少倒扣与深凹槽。
- 内部封闭空腔无法拆除支撑，设计时预留开口或改用可溶解支撑方案。
- 外观面避免与支撑直接接触，把支撑接触面放到背面或底面。

## 3. 打印方向决定强度

- 层间结合是零件最薄弱的截面；受力方向尽量与层间结合面垂直或错开，不要让主要拉力直接沿层间方向撕开。
- 长条形零件的打印方向同时影响支撑量、尺寸精度与强度，建模时就要选定朝向。

## 4. 配合与公差

- 轴孔、卡扣、插接件在建模时预留配合间隙，按当前材料与实测结果微调，常见预留量约 0.2–0.4 mm。
- X2D 自动轴孔补偿仅支持垂直正圆孔，水平孔、斜孔与非正圆孔需手工预留间隙。
- 活动件（铰链、齿轮、关节）先打配合测试件验证松紧，再打印正式件。

## 5. 圆角、尖角与应力集中

- 尖角悬空容易脱落，边角尽量加圆角。
- 受力根部加圆角分散应力，避免直角根部层间撕裂。
- 避免大面积悬空薄板，必要时加加强筋。

## 6. 连接结构

- **热熔螺母柱**：在模型中预留螺母外径与埋入深度孔位，柱壁留出合理厚度。
- **卡扣悬臂**：控制悬臂长度、厚度与回弹角度，根部加圆角，材料韧性满足反复开合。
- **螺丝柱**：预留内孔直径与沉头空间，柱体高度与打印方向匹配。
- 大模型拆件时设计定位榫与粘合面，而不是打印完随意切割。

## 7. 设计检查清单

- [ ] 壁厚均匀且满足最小壁厚要求。
- [ ] 主要受力方向避开层间薄弱面。
- [ ] 配合部位预留间隙并准备测试件。
- [ ] 悬垂、倒扣与内部支撑在可拆除范围内。
- [ ] 螺母柱、卡扣、加强筋结构完整。
- [ ] 模型为闭合实体，无破面与零厚度区域。
- [ ] 整体尺寸与摆放方向在打印板范围内。
