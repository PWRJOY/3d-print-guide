# 建模与面向打印的设计

会下载模型打印只是第一步；能把自己的想法建成可打印模型，才进入设计阶段。本板块给出软件学习顺序与面向 3D 打印的设计规范。

## 软件学习顺序

1. [Tinkercad 入门](/modeling/tinkercad)：浏览器免费，先建立三维空间、组合与导出 STL 的直觉。
2. [Fusion 360 参数化建模](/modeling/fusion-360)：工程件主力，草图约束、特征、装配与公差。
3. [Blender 有机造型](/modeling/blender)：角色、手办、曲面等自由形态模型，与参数化 CAD 是两套思维。
4. [DfAM 打印设计规范](/modeling/design-rules)：壁厚、悬垂、公差、卡扣、螺母柱等打印专属规则。

## 两条建模路线的区别

- **参数化 CAD（Fusion 360）**：由尺寸与约束驱动，适合支架、外壳、机构件、装配体；改尺寸可回溯。
- **有机造型（Blender）**：由网格雕刻与曲面驱动，适合手办、角色、异形外观；需要额外做网格修复与壁厚处理。

不要一开始同时学两套软件；先按自己常做的作品类型选择主线。
