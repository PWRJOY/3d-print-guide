# Tinkercad 入门

## 定位

Tinkercad 是浏览器端免费建模工具，操作以基本几何体的加减组合为主，适合第一次理解三维空间、视角、对齐与导出流程。

## 练习路径

1. 熟悉视角旋转、平移、缩放与视图切换。
2. 用立方体、圆柱、球体组合出一个简单收纳盒或支架。
3. 练习对齐、复制、分组、打孔与添加文字。
4. 把已有模型缩放、改尺寸、加孔位后导出 STL 打印。

## 能解决什么

- 修改下载模型的尺寸、孔位与文字标注。
- 制作简单的规则几何体零件与装配试装件。
- 建立「模型 → STL → 切片 → 打印」的完整闭环直觉。

## 什么时候升级到 Fusion 360

当你需要精确尺寸约束、圆角、壳体、多零件装配、可参数化修改时，转入 [Fusion 360](/modeling/fusion-360)。
