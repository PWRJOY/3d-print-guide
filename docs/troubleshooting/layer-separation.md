# 层间分离与开裂

## 现象

零件沿层与层之间裂开、侧面分层、受力后沿层间断开；表面可见层与层结合不牢的缝隙。

## 成因与对策

### 喷嘴温度偏低

层与层需要足够热量才能熔合。按材料配置文件，以 5–10 ℃ 为步长上调喷嘴温度，每层打印后对比层间结合，不要一次大幅升温。

### 冷却过强

- PLA 需要充分冷却定型；ABS、ASA、PC、PA 等材料冷却风扇过强会让新层迅速冷却，来不及结合。
- 按材料降低部件冷却风扇转速，工程材料配合主动腔温保持环境热量。

### 速度过快

速度超过热端熔化与挤出能力时，层间供料不充分。适当降低速度，先在小测试件上验证。

### 耗材受潮

受潮降解的材料层间结合显著下降；先干燥耗材，规范见 [吸湿、干燥与存储](/materials/drying-storage)。

### 腔温不足

ABS、ASA、PA、PC 等材料在腔温不足时，外层快速冷却收缩，内部结合被拉开。开启并稳定腔温，避免开门打印。

## 排查顺序

1. 确认耗材干燥。
2. 核对材料对应的冷却风扇策略。
3. 小步上调喷嘴温度。
4. 降低速度。
5. 工程材料确认腔温已开启并稳定。

每一步只改一个变量，用对比件验证。
