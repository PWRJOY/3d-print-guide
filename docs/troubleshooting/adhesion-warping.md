# 附着不良与翘边

## 现象

首层局部不粘板、边角向上翘起、大面积底面脱离板面；ABS、ASA、PC 等材料更容易出现冷却收缩拉扯。

## 排查顺序

### 1. 检查板面

- PEI 板表面是否有指纹、油污、旧料残留；用异丙醇清洁后重新测试。
- 打印板是否安装平整、卡扣到位。
- 板面是否有明显划痕或老化区域，必要时更换打印板。

### 2. 复核调平与喷嘴高度

- 重新执行热床调平；搬动机器、拆装热板后必须重新调平。
- 观察首层测试片：料线应平铺成连续扁带，而不是挤出成圆线或压得过扁。

### 3. 核对温度

- 按材料核对热床温度，温度偏低会削弱附着。
- 喷嘴温度过低会导致首层熔融不充分；参考材料对应配置文件。

### 4. 排除受潮

- 耗材受潮会造成首层出料不稳、气泡与附着不良；先干燥耗材再测试，见 [吸湿、干燥与存储](/materials/drying-storage)。

### 5. 结构与环境

- 大面积底面可加裙边（brim）扩大附着面积。
- ABS/ASA/PC 开启主动腔温，减小内外温差；避免气流直吹板面。
- 确认环境温度在 10–30 ℃ 要求范围内。

## 什么时候升级处理

以上步骤完成后仍大面积翘边，检查喷嘴高度校准、打印板类型是否匹配当前材料，必要时更换对应材料的打印板。
