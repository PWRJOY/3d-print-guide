# 堵头与出料中断

## 现象

挤出机齿轮空转打滑、喷嘴不出料、出料断断续续、模型局部缺料；严重时线材在挤出机附近堆积。

## 常见成因

- 耗材受潮降解，在热端形成碳化残留。
- 杂质、纤维增强材料磨损堆积在喷嘴与喉管。
- 喷嘴温度过低，材料在喉管内凝固堵塞。
- 长时间高温停留造成积碳。
- 耗材直径不规范或送料路径折弯、卡顿。

## 处理流程

### 1. 冷拔（cold pull / atomic pull）

1. 将喷嘴加热到当前材料打印温度，手动推入一段干净耗材。
2. 降温到适合拔料的温度后，平稳拉出耗材；拉出的料头应带出残留杂质。
3. 重复直到料头干净顺滑；尼龙适合作为冷拔清理料，具体操作以官方 Wiki 指南为准。

### 2. 检查送料路径

- 线材盘架转动顺畅，没有缠绕打结。
- 进料管与挤出机入口无折弯、无挤压。
- TPU 等软料确认速度与路径策略符合材料要求。

### 3. 更换喷嘴

冷拔无法恢复时，使用 X2D 免工具换喷嘴流程更换喷嘴；更换后重新执行流量校准。喷嘴寿命与更换周期见 [维护保养](/maintenance/)。

### 4. 回溯材料原因

- 纤维增强材料按官方兼容清单选择喷嘴；磨损异常时核对材料与喷嘴组合。
- 反复堵头时检查耗材是否受潮、是否混有杂质或不同材料残留。

## 预防

- 耗材密封干燥存放。
- 打印结束按规范退料，避免材料长期留在热端碳化。
- 定期检查喷嘴与喉管状态，见 [维护保养周期表](/maintenance/)。
