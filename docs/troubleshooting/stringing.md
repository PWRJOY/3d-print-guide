# 拉丝与牵丝

## 现象

喷嘴在悬空移动时拖出细丝，挂在转角、镂空与模型表面，形成毛刺与网状牵丝。

## 排查顺序

### 1. 先排除耗材受潮

受潮材料在喷嘴内产生气泡与不规则出料，是拉丝的常见诱因。干燥耗材后再对比，见 [吸湿、干燥与存储](/materials/drying-storage)。

### 2. 核对回抽参数

- 沿用材料官方预设的回抽距离与速度，不要凭感觉大幅加大。
- 回抽不足：喷嘴离开前未把线材抽回，移动时继续滴料。
- 回抽过度：可能造成挤出波动与堵头风险，按测试件结果微调。

### 3. 温度与流动性

- 喷嘴温度偏高会让材料流动性过强，移动时更容易滴料；在材料允许范围内小幅降温对比。
- 不要在未确认其他因素前同时改温度与回抽。

### 4. 空置移动路径

- 检查切片中的空置移动策略，减少模型上方长距离空走。
- 对比不同移动速度下的拉丝表现。

## 验证方法

打印标准拉丝测试件，分别在改动前后对比表面细丝数量；确认改动有效后再应用到正式模型。
