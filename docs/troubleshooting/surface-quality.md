# 表面质量问题

本页覆盖侧壁粗糙、振纹/鬼影、边缘模糊、顶面不平与条纹等问题。

## 侧壁粗糙、层纹明显

- 核对层高选择：外观件使用更小层高，见 [层高与表面质量](/slicer/layer-height)。
- 检查流量校准是否执行；挤出量偏差会在侧壁形成规律性纹路。
- 确认线宽与壁厚匹配，避免半线宽路径。

## 振纹、鬼影、边缘模糊

- 执行振动补偿；搬动机器或拆装运动部件后重新校准。
- 降低打印速度，观察振纹是否减轻。
- 确认机器放置平稳、台面无晃动，皮带张紧状态正常，见 [维护保养](/maintenance/)。

## 顶面凹陷、条纹、不平整

- 增加顶面层数，保证顶面封闭。
- 检查顶面冷却是否均匀，冷却风扇状态是否正常。
- 复核流量校准与挤出参数，排除出料波动。

## 局部表面溢料或缺料

- 溢料：温度、回抽或线宽偏大，按 [拉丝与牵丝](/troubleshooting/stringing) 与 [速度、温度与冷却](/slicer/speed-cooling) 排查。
- 缺料：先确认是否堵头，见 [堵头与出料中断](/troubleshooting/clogging)；再核对流量与耗材干燥状态。

## 排查顺序

1. 先确认校准（调平、流量、振动补偿）为最新状态。
2. 区分问题出在侧壁、顶面还是悬垂面，对应到切片参数。
3. 一次只改一个参数，用测试件对比。
4. 软件参数无法消除的痕迹，进入 [后处理](/post-processing/) 流程打磨修整。
