# 双喷嘴专题

X2D 的双喷嘴系统承担两类任务：**多色/多材料组合**，以及**主体 + 支撑材料分工**。本板块说明两种用法的规则、材料分工与注意事项。

## 两篇专题

- [双色与多色打印](/dual-nozzle/dual-color)：颜色分区、材料组合、切换损耗与策略。
- [易拆支撑与水溶支撑](/dual-nozzle/support-material)：辅助喷嘴支撑材料、PVA 使用规范与拆除流程。

## 双喷嘴通用规则

- 主喷嘴用于模型主体，质量与校准能力优先；辅助喷嘴用于支撑与换色。
- 辅助喷嘴打印质量略低于主喷嘴，建议优先使用官方耗材。
- TPU 不推荐辅助喷嘴；谨慎材料清单见 [机型参数表](/printers/x2d)。
- 双喷嘴模型在切片前先确认两个喷嘴的耗材、温度与板面附着组合兼容。
