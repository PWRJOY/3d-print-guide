# 双色与多色打印

## 适用场景

- 模型分区配色：主体一种颜色，文字、标识、装饰件另一种颜色。
- 软硬组合：主喷嘴硬质结构，辅助喷嘴柔性缓冲件（TPU 走主喷嘴规则以 [机型参数表](/printers/x2d) 为准）。
- 不同材料功能组合：刚性骨架与柔性接触面一次成型。

## 切片前检查

1. 两个喷嘴分别装入目标耗材，确认送料顺畅、耗材干燥。
2. 在 Bambu Studio 中为模型区域分配颜色或材料；核对分区边界是否清晰。
3. 检查两种材料的温度窗口是否接近；温差过大时评估切换策略与等待时间。
4. 确认辅助喷嘴所选耗材在兼容清单内。

## 切换与损耗

- 喷嘴切换由工具头机构完成；换色过程会产生少量废料，观察废料滑梯与清理通道是否畅通。
- 颜色交界处注意层间结合与溢色；边界层参数按官方预设起步。
- 多色方案配合 AMS 可扩展更多颜色；余料与用量检测配合 AMS 使用。

## 常见问题

- **交界处拉丝、混色**：核对回抽、温度与空置移动路径，参考 [拉丝与牵丝](/troubleshooting/stringing)。
- **辅助喷嘴表面质量差**：确认耗材为官方推荐材料，谨慎类材料改走主喷嘴。
- **分区错位**：检查模型分区与喷嘴分配是否对应，复核自动轴孔补偿等相关设置。
