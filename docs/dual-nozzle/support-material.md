# 易拆支撑与水溶支撑

## 两种支撑路线

### 易拆支撑（辅助喷嘴专用 PLA / PETG / ABS 等支撑料）

- 主体与支撑材料收缩、附着特性不同，成型后可以从接触面剥离。
- 适合外部悬垂、褶皱、凹槽等能伸手拆除的结构。
- 接触面质量决定拆除后表面痕迹；参数关注点见 [支撑策略](/slicer/supports)。

### PVA 水溶支撑

- PVA 遇水溶解，用于普通工具无法伸入的复杂内腔、孔洞与悬空结构。
- 由辅助喷嘴打印，主体材料按目标用途选择。
- 拆除后将模型浸泡在水中直至支撑溶解，中途换水；确认主体材料本身耐水。

## PVA 使用规则

- **极易吸湿**：未使用部分必须密封干燥存放，上机前确认干燥状态，规范见 [吸湿、干燥与存储](/materials/drying-storage)。
- 仅作为支撑材料，不单独打印受力主体件。
- 溶解过程需要耐心，不要用尖锐工具硬撬损坏内腔表面。

## 双喷嘴支撑规划流程

1. 先在 [支撑策略](/slicer/supports) 中判断摆放方向能否减少支撑。
2. 外部可拆除结构选易拆支撑；封闭内腔选 PVA 水溶支撑。
3. 切片时确认主体喷嘴与支撑喷嘴的材料、温度分配正确。
4. 成型后按材料类型选择机械剥离或水溶流程。
