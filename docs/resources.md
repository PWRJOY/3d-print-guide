# 外部资源汇总

本站内容为个人学习手册；遇到具体问题时，以下官方与社区渠道是优先查证入口。

## 官方资料

- [Bambu Lab Wiki（中文）](https://wiki.bambulab.com/zh/home)：校准、故障排查、材料指南，遇到问题的第一入口。
- [Bambu Lab Academy](https://wiki.bambulab.com/zh/home)：官方系统课程，从设备操作到软件进阶。
- [拓竹 X2D 技术参数（官方）](https://bambulab.cn/zh-cn/x2d/specs)
- [拓竹 X2D 产品介绍（官方）](https://bambulab.com/zh/x2d)
- [MakerWorld 模型社区](https://makerworld.com/)：已针对拓竹设备调校参数的模型平台；下载前查看作者标注的适用机型与打印备注。

## 软件

- Bambu Studio：电脑端切片与参数配置（Windows / macOS / Linux）。
- Bambu Handy：手机端监控、选模型与远程打印。
- 第三方切片：SuperSlicer、PrusaSlicer、Cura 可导出标准 G 代码，但官方智能校准与补偿功能不可用。

## 社区与经验交流

- Reddit [r/BambuLab](https://www.reddit.com/r/BambuLab)：拓竹机型专属社区，AMS、多色与切片参数讨论活跃。
- Reddit [r/3Dprinting](https://www.reddit.com/r/3Dprinting)：通用 FDM 工艺与故障排查，发失败照片通常能获得诊断建议。
- 中文视频平台与视频网站：检索机型 + 材料名查看实战案例；注意区分官方教程与个人经验，经验参数需结合自己的设备验证。

## 学习原则

- 官方 Wiki 与厂商文档优先于社区经验帖。
- 别人的参数只作为起点，必须用自己的材料、机器与测试件验证。
- 记录每个有效方案的条件：材料批次、环境温度、喷嘴直径、模型结构，避免脱离条件照搬参数。
