# 后处理工艺

后处理决定打印件从"能看"到"可用、好看"。打印结束后的取件是第一步，之后才是拆支撑、打磨、上色、装配与表面强化。

## 1. 打印结束后的取件时机

核心原则：**打印完成后不要立即取件**，等打印板降温到 40℃ 以下（手摸温温的、不烫）再取，对多数材料最稳妥。

### 按材料的等待时间

| 材料 | 建议等待 | 说明 |
|---|---|---|
| PLA | 5–15 分钟 | 热床 55–60℃ 降到 40℃ 以下即可；X2D 增稳低温打印板冷却后会自动松脱 |
| PETG | 10–20 分钟 | 降到 40℃ 以下再取，热态取容易翘边 |
| ABS / ASA | 15–30 分钟 | 等腔温一起降下来，骤冷容易开裂、翘边 |
| 大件 / 易变形件 | 等完全冷却 | 局部应力未释放，热取容易变形 |

### 为什么不等热取

- PLA 在 60℃ 附近开始变软，热床还烫时强行取件，底板容易弯、变形。
- 骤冷会翘边：ABS、PETG 刚从热床取下时温差大，边缘收缩上翘。
- 暴力撬伤板：金属铲硬撬既伤打印板涂层，也容易掰断细的支撑。

### X2D 实操提示

- 官方增稳低温打印板配合 PLA：打完等自然冷却，板面收缩后模型会自动松脱，基本不用铲。
- PETG 与工程材料等温度明显下降、不烫手再取。
- 取下的打印件放平面上自然冷却，不要直接放金属台面（局部散热过快容易翘曲）。

## 2. 拆除支撑与残留

- 先取下主体与支撑，用笔刀清理大的支撑触点与残留堆料。
- 水溶支撑按 [易拆支撑与水溶支撑](/dual-nozzle/support-material) 的流程浸泡溶解。
- 不要在未拆净支撑前开始打磨，避免支撑碎屑嵌入表面。

## 3. 砂纸打磨

### 逐级打磨原则

砂纸必须从粗到细逐级递进，跳级会留下粗划痕，细砂无法磨除。

1. 粗目数（约 120–240 目）：去除层纹台阶、支撑痕迹与毛刺。
2. 中目数（400 目）：消去粗砂划痕，统一表面。
3. 细目数（800–1200 目）：为上色打底。
4. 高光需求再到 2000 目以上精磨。

### 操作要点

- 砂纸绕在平整木块或海绵块上，保证受力均匀，避免磨出凹坑。
- 沿层纹走向单向打磨，不要随意画圈。
- 可轻蘸水打磨减少粉尘，同时让表面更均匀；打磨后彻底干燥再进入下一步。
- 细小沟槽用竹签卷砂纸处理，不要硬塞整块砂纸。

## 4. 补土与上色

1. 打磨后清洁表面粉尘，保持干燥。
2. 刮涂或喷涂补土（primer/filler）填平细小凹坑与层纹，干燥后再次细磨。
3. 底漆层均匀覆盖，检查暴露的划痕与凹陷，局部修补后再喷面漆。
4. 面漆按薄喷多层，控制每层厚度避免流挂；最后按需要喷保护清漆。
5. 全程保持通风，遵守涂料安全说明。

## 5. 机械装配

### 攻丝

- 螺纹孔按材料与螺钉规格选择钻头预留孔径，再用对应丝锥攻丝。
- 脆性材料（PLA）反复拆装能力弱，受力连接优先用热熔螺母或通孔螺丝。

### 热熔螺母

- 按螺母外径在模型中预留孔位，用电烙铁或专用工具将螺母压入，使周围材料轻微熔融包紧。
- 螺母柱壁厚不足会开裂；孔位深度与外径按螺母规格核对。

### 粘合

- 材料与胶水匹配：结构件按材料选择专用胶；粘接面预留贴合面积与定位结构。
- 大件先做定位榫与夹具固定，待胶水固化后再松开。

## 6. 表面强化（按需）

- ABS 可用丙酮蒸汽做表面溶解光滑处理，注意通风与安全，仅适用于对应材料。
- 其他材料以打磨、补土与喷漆为主；化学光滑方法先在废料件上试验。

## 7. 流程顺序总览

取件 → 拆支撑 → 粗磨 → 中磨 → 细磨 → 补土 → 打磨补土痕 → 底漆 → 面漆 → 保护漆 → 攻丝/压螺母/粘合装配。
